## 十一、拍摄建议

1. **一定要有"证据"画面**：微信里的真实对话、记忆页的强度条、日志里的"已自动切换"。比讲概念有效 10 倍。
2. **前 3 秒给结果**：先放"它记得我养两只猫"的对话截图，再讲原理。
3. **数字比形容词有用**："琐事 3 天淡忘、重要 1 个月、48K 自动压缩"，观众会记住数字。
4. **录屏用竖屏**：控制台在 1440 宽下截图后裁成 9:16，或直接手机拍屏。
5. **打码**：真实联系人昵称、头像、微信号一律打码。用"小明""小红"这种假名重录一遍最安全。
6. **结尾留钩子**：不要说完就结束，留一句"想看它怎么记住群成员？下条拍"。
7. **评论区自己先置顶**：抖音很多人不看简介只看评论。

## 十二、合规提醒

- 别提"自动回复营销/引流/群发"，容易被判定违规。
- 别展示真实聊天内容与他人隐私。
- 说明这是**个人电脑上运行的工具**，不是云端服务，避免用户误解。
- 微信官方对第三方工具有态度，文案里不要承诺"绝不封号"，用"自担风险""建议小号试"。
- 别把 API Key、Token、二维码等敏感信息拍进画面。
