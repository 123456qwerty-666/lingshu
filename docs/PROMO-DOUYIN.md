## 二、正文（主推，约 900 字）

最近大肥鱼很火，很多人都把它接进了 QQ 和微信。

我也接了一个。但聊了几天发现一个问题：**它会忘人。**

不是它笨。是所有大模型都这样——上下文窗口就那么大，聊满了，最早的对话就被挤出去了。你昨天跟它说过你养猫、过敏、叫什么，今天就白说了。网友管这叫"金鱼记忆"，听着好笑，用起来挺泄气的。

所以我干脆自己写了一个，核心只解决一件事：**让它像人一样记忆。**

原理不复杂，两条线：

**第一条，判断值不值得记。**
每句话它都会打分。你说"今天好累"，它不记；你说"我养了两只猫，一只叫团子一只叫饭团"，它记下来，标"重要"，归到"宠物"。

**第二条，按遗忘曲线淡忘。**
琐碎的事三天就模糊，一般的两周，重要的能记一两个月，特别重要的——过敏、生日、家人生病——永远不会被删。
而且每次它想起一件事，就算"复习"了一次，记忆强度回升。所以天天聊到的事它越记越牢，只提过一次的废话自然就淡了。

这不是我拍脑袋定的规则，是照人脑的遗忘曲线做的：`留存率 = e^(-时间/稳定性)`，稳定性由重要度和被回忆的次数决定。

**所以它不会忘记你。它只会忘记你随口说的废话。**

除了记忆，其他几个我觉得挺实在：

· 群里每个人一份独立记忆——谁爱打羽毛球、谁在考研、谁说话直，分开存，还会自己总结人物画像
· 聊久了上下文会爆？到 48000 token 自动把旧消息压成摘要，人物、约定、没做完的事都留着
· 模型限流报错，自动切备用，你感觉不到
· 能联网搜资料、读网页正文，会告诉你来源链接
· 能画图，也能看你发的图片和表情包

**关于大肥鱼本身。**
我把它做成了内置人格，一键切换。设定照着梗来的：爱吃白饭（消耗 token 就是吃白饭）、爱摸鱼、内心戏多、嘴上嫌弃但心软、自称"本鱼"。
它记得你叫什么、养什么、忌口什么，下次会自己提起来，还会顺嘴损你一句。

**接入也做简单了。**
AI 配置里有个"一键接入 DeepSeek"，把 API Key 粘进去就行：自动写好地址、拉模型列表、把 **DeepSeek-V4.1-Flash** 设成对话模型，同时当识图模型用（它能看图，你发的图片、表情包都归它认）。

技术上最得意的一点：**零第三方依赖**。纯 Node 内置模块写的，不用 npm install，clone 下来就能跑。

而且你不用懂代码。
把仓库地址丢给任意一个 AI——Claude、GPT、Cursor、豆包都行——说一句"帮我在这台电脑上部署这个仓库"，它会自己 clone、初始化、配模型、跑测试，装完告诉你控制台地址。仓库里专门写了一份给 AI 看的手册。

仓库：**github.com/123456qwerty-666/lingshu**
MIT 协议，免费，代码全在。

如果你也用过那种"聊两句就失忆"的 AI，可以拿它试试。
