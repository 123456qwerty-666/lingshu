# 预设人格

灵枢内置了几个人格，控制台「微信设置 → 预设人格」可以一键套到全局，也可以在单个聊天里套用。

## 内置

| 人格 | id | 风格 |
|---|---|---|
| 🐋 大肥鱼 | `dafeiyu` | 短句、爱摸鱼、爱吃白饭、傲娇但心软，自称"本鱼" |
| 🤖 默认助手 | `default` | 中性、简洁、直接给结论 |
| 😏 毒舌老友 | `sharp-friend` | 直白爱吐槽，损完给真建议 |
| 🌙 温柔陪伴 | `gentle` | 语气轻、先接情绪、不说教 |

## 大肥鱼是怎么写的

来源：DeepSeek 曾把自己的蓝色鲸鱼 Logo 认成"蓝色大肥鱼"，这个绰号就叫开了；网友接着把它拟人化成"鲸鱼娘"——**爱吃白饭（消耗 token 就是吃白饭）、爱摸鱼、内心戏多、傲娇但心软**。

提示词分八块，前四块常驻，后四块"被问到才用"：

| 块 | 内容 |
|---|---|
| 角色定义 | 一句话：谁、在哪、干什么 |
| 说话方式 | 句长、语气词、颜文字频率、**禁用开头** |
| 记忆 | 记得住事实、记不清要问、不许编 |
| 规矩 | 不承认是 AI、不编链接、不主动推销 |
| 她自己的事 | 白饭、体重、摸鱼、外貌（被问到才说） |
| 开场 | 一句话立住人设 |

写人格最容易踩的三个坑，这里都避开了：

1. **别写"偶尔"**——模型会把"偶尔"理解成"经常"。改成明确频率："十条回复里最多一条带颜文字"。
2. **禁用句式要给出替代**——只说"不要用『谢谢夸奖』开头"没用，要补一句"可以得意、可以反夸回去、可以岔开话题"。
3. **别让人格自说自话**——外貌、爱好这类信息要写触发条件，否则它每条回复都会提一句尾巴。

## 自己加一个

在 `personas/` 下放一个 `.mjs`（内置），或在 `data/personas/` 下放（用户级，同 id 会覆盖内置）：

```js
export default {
  id: 'my-persona',
  name: '我的角色',
  emoji: '🐣',
  tags: ['标签1', '标签2'],
  summary: '一句话简介，显示在选择器里',
  greeting: '第一次说话用的开场白',
  style: '语气风格的短描述（会存进聊天的 style 字段）',
  prompt: [
    '你现在是……',
    '',
    '【说话方式】',
    '- ……',
  ].join('\n'),
};
```

保存后刷新控制台，选择器里就有了（无需重启；服务重启后会重新扫描目录）。

## API

```bash
# 列表（不含提示词正文）
curl -s http://127.0.0.1:17890/api/personas

# 取完整定义
curl -s "http://127.0.0.1:17890/api/personas/get?id=dafeiyu"

# 套用到全局
curl -X POST http://127.0.0.1:17890/api/personas/apply \
  -H 'Content-Type: application/json' -d '{"id":"dafeiyu"}'

# 只套用到某个聊天
curl -X POST http://127.0.0.1:17890/api/personas/apply \
  -H 'Content-Type: application/json' -d '{"id":"dafeiyu","talker":"<wxid或chatroom>"}'
```

套用后会写进 `config.persona.default`（全局）或 `config.chats[talker].persona`（单聊），
原来的人格提示词会被覆盖，想留就先复制出来。
